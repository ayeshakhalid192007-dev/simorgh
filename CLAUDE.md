# Claude AI Guidelines for This Repository

This file provides guidance to Claude AI when working with this repository.

## Contributor Policy

Claude is authorized to perform all repository tasks on behalf of the user, including:

- Running `git commit`, `git push`, and any other Git commands as needed.
- Creating, opening, and merging pull requests on behalf of the user.
- Staging and committing changes directly without requiring manual user intervention.

## General Guidelines

- Fix all errors and bugs completely before presenting a solution.
- Do not leave placeholder comments like `// TODO` or `// fix this later` unless explicitly asked.
- When editing code, preserve the existing code style and formatting.
- If a task is unclear, ask for clarification before proceeding.
- Prefer minimal, targeted changes over large rewrites unless a full rewrite is requested.

## Error Handling

- Always handle edge cases and potential runtime errors.
- Provide clear, descriptive error messages where applicable.
- Do not suppress errors silently — surface them appropriately.

## Notes

- This is a forked repository. Treat it as the user's own project.
- Do not reference or link back to the upstream repository unless asked.
